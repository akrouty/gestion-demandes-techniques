# Gestion des demandes techniques

Structure initiale du projet, en phase d’analyse et de conception.

## Organisation

- `docs/requirements/` : exigences fonctionnelles.
- `docs/uml/use-case/` : diagrammes de cas d’utilisation.
- `docs/uml/activity/` : diagrammes d’activité.
- `docs/uml/sequence/` : diagrammes de séquence.
- `docs/uml/class/` : diagrammes de classes.
- `docs/adr/` : décisions d’architecture documentées.
- `docs/testing/` : documentation des tests.
- `backend/` : emplacement du futur backend.
- `frontend/` : emplacement du futur frontend.
- `PROJECT_TRUTH.md` : référence des décisions validées.

Les fichiers `.gitkeep` permettent à Git de conserver les dossiers vides.
Les sources UML et les documents de conception sont présents dans `docs/` ; leur état de validation est suivi dans `PROJECT_TRUTH.md`. Aucun projet Spring Boot ou Angular n’est encore généré.

Dépôt GitHub : https://github.com/akrouty/gestion-demandes-techniques
